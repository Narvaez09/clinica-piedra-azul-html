# Clínica Piedra Azul — HTML

Proyecto web de la Clínica Piedra Azul desarrollado utilizando HTML, CSS, JavaScript y Bootstrap.

La página presenta información de la clínica, médicos y especialidades, promociones, un formulario de registro con validaciones, una sección de productos y un diseño adaptable a diferentes tamaños de pantalla.

## Video de presentación

[Ver video del proyecto](https://youtu.be/ZCAUScEHbwc)

## Tecnologías utilizadas

* HTML5
* CSS3
* JavaScript
* Bootstrap
* Bootstrap Icons

## Secciones de la página

* Encabezado
* Barra de navegación
* Carrusel de promociones
* Médicos y especialidades
* Formulario de registro
* Productos
* Footer

## Funcionalidades

* Navegación entre las diferentes secciones de la página.
* Carrusel de imágenes promocionales.
* Visualización de información de médicos y especialidades.
* Cambio de información al seleccionar una especialidad.
* Validación de los campos del formulario mediante JavaScript.
* Validación de correo, teléfono, documento y contraseña.
* Confirmación de contraseña.
* Diseño responsive utilizando Bootstrap.
* Efectos visuales en las tarjetas de productos y médicos.
